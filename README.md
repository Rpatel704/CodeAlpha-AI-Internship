# CodeAlpha AI Internship Projects

This repository contains two AI projects developed as part of the CodeAlpha Artificial Intelligence Internship.

## Task 1 — AI Language Translation Tool

A web-based language translation application built using Python and Flask.

### Features
- Translation between multiple languages
- Source and target language selection
- Automatic source language detection
- Translation API integration
- Responsive web interface
- Language swapping

### Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- Translation API

## Task 2 — AI FAQ Chatbot

An NLP-based FAQ chatbot that finds the most relevant answer from a predefined FAQ knowledge base.

### Features
- Natural language FAQ matching
- TF-IDF vectorization
- Cosine similarity
- JSON-based FAQ knowledge base
- Similarity threshold for unknown questions
- Interactive web interface

### Technologies
- Python
- Flask
- Scikit-learn
- TF-IDF
- Cosine Similarity
- HTML
- CSS
- JavaScript
- JSON
